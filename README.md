# Docencia Programas en Energías

Sitio de apoyo docente para los programas de **Ingeniería en Energías** y **Tecnología en Gestión de Energías Renovables** de la Universidad de La Guajira: formatos, tutoriales, calendario académico 2026-2 y enlaces institucionales.

Publicado con GitHub Pages: https://andressalcedob.github.io/docencia-energias/

Para actualizar el contenido, edita `index.html`. Las filas del calendario usan los atributos `data-s` (inicio) y `data-e` (fin) en formato AAAA-MM-DD para marcarse solas como *En curso* o *Próximo*.
